# Vessel · SandBase Lab — AI City Remix

An interactive Vessel-inspired architectural showcase built with Three.js, TypeScript and Vite.

## Run locally

```sh
npm ci
npm run dev
```

## Deploy on Vercel

Import this repository. Framework: Vite. Build command: `npm run build`. Output directory: `dist`.
Keep package.json at the repository root. No API key or server is required.

## Controls

Drag to orbit, scroll to zoom, right-drag to pan. Hold W/S to dolly, Shift for precision, R to reset. Exterior, interior, top-down, walking route and guided tour controls are available on screen.
